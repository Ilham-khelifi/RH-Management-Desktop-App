# 🧑‍💼 HR Management System – Desktop Application

## 📌 Project Overview
This project is a **Desktop Human Resources Management System** developed as a **Final Year Project (PFE)**.  
It aims to modernize and automate HR processes that were previously handled manually using Excel, Word, and paper archives.

The application is designed to work **offline**, on a **single workstation**, without requiring internet or a local network.

---

## 🎯 Objectives
- Centralize all employee data in a secure database
- Automate HR processes (employees, leaves, absences, training, evaluations)
- Ensure data integrity, security, and traceability
- Reduce human errors and administrative workload
- Provide a user-friendly graphical interface

---

## 🛠️ Technologies Used
- **Programming Language:** Python  
- **GUI Framework:** PyQt5  
- **Database:** MySQL  
- **ORM:** SQLAlchemy  
- **Architecture:** MVC (Model–View–Controller)

---

## ✨ Main Features
- Secure authentication with role management (Admin / RH User)
- Employee management (add, edit, archive, search)
- Leave and absence management
- Training and evaluation tracking
- Action history (logging / traceability)
- PDF report generation
- Offline usage (no Internet required)
